# Fonts for SEIP PDF generation

| File | Use |
|---|---|
| `NotoSansThai-Regular.ttf` | Embedded in PA report PDFs (`apps/api` pdfkit) |

Source: Google Noto Sans Thai (SIL Open Font License 1.1).
Re-download if missing:

```bash
# example
curl -L -o assets/fonts/NotoSansThai-Regular.ttf \
  "https://github.com/googlefonts/noto-fonts/raw/main/hinted/ttf/NotoSansThai/NotoSansThai-Regular.ttf"
```
