# System Context

SEIP receives evidence from teachers and administrators, stores original files and metadata, uses AI to suggest classifications and indicator mappings, allows human review, and generates evaluation reports for two configurable cycles per year.

## External Actors
- Teacher
- Director and deputy director
- Evaluator
- School administrator
- Area administrator
- AI provider
- Object storage
- Notification service

## Core Principle
Upload once, reuse through governed mappings in multiple reports.
