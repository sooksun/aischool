# ADR-0015: Portfolio เป็นของบุคคล, สพท. เป็น controller, สิทธิ์แบบ grant และการยืนยันสองชั้น

## Status
**Proposed** (2026-10-12) — เสนอใน P0 และต้องผ่านการตรวจทางกฎหมาย (AQ-09). แก้ data model ของ DB-000 และสิทธิ์ครูใน `permissions.yaml` ไม่ได้แทนที่ ADR ใดทั้งฉบับ

## Context
- D2: สพท. เป็นผู้ควบคุมข้อมูล (controller), โรงเรียนเป็น tenant และ portfolio ของครูต้องติดตัวไปเมื่อย้ายโรงเรียน
- data model ปัจจุบันผูก `Evidence.schoolId` ไว้กับโรงเรียน ถ้าครูย้ายโรงเรียน หลักฐานจะไม่ตามไป
- ปัจจุบันมีแค่ ผอ./ผู้ดูแลระบบโรงเรียนที่ยืนยัน mapping ได้ แต่ PRD (FR-040) กำหนดให้การยืนยันของครูเองมีผลจริง
- หลักฐานบางชิ้นมีข้อมูลของนักเรียน ซึ่งอยู่ภายใต้ controller ของโรงเรียนหรือเขต

## Decision
1. **หลักฐานเป็นของบุคคล** และ `controller_area_id` ระบุ สพท. ที่ถือครองข้อมูล
2. โรงเรียน, ผอ., กรรมการ และ สพท. ได้สิทธิ์ผ่าน **`evidence_grant`** ไม่ได้ผ่านความเป็นเจ้าของ
3. **การยืนยันสองชั้น**:
   - สถานะของ mapping มี 4 สถานะคือ `owner_confirmed`, `validated`, `returned`, `revoked`
   - ชั้นแรก ครูเจ้าของหลักฐานตั้งเป็น `owner_confirmed`
   - ชั้นที่สอง ผอ. หรือกรรมการตั้งเป็น `validated` หรือ `returned`
   - **คำแนะนำของ AI อยู่ในตาราง `ai_suggestion`** ไม่ปนกับ mapping
4. **ย้ายโรงเรียนในเขตเดียวกัน**: เปลี่ยนเฉพาะการจ้างงานและ grant
5. **ย้ายข้ามเขต**: ต้องมีข้อตกลงระหว่าง controller ทั้งสองฝ่าย. ไฟล์ต้นฉบับที่ระบุตัวนักเรียนได้ย้ายได้เฉพาะในรูปที่เบลอแล้ว เว้นแต่เขตเดิมอนุมัติ
6. ครูได้ **portability export** (PDPA ม.31)
7. ถ้า crosswalk ของตัวชี้วัดเปลี่ยน (framework แก้ไข) เจ้าของต้องยืนยันใหม่

## Consequences
- RLS backstop ใช้ `controller_area_id` (ADR-0012)
- กรรมการเห็นเฉพาะ link ที่ครูยืนยันแล้ว พร้อม quote, locator และป้ายที่มา **ไม่เห็นความมั่นใจของ AI, คำใบ้ระดับ, เหตุผลของ AI หรือสรุปที่ AI เขียน** ใน v1 เพื่อลด automation bias
- ข้อสันนิษฐานว่า สพท. เป็น controller ต้องให้ที่ปรึกษากฎหมาย/DPO ยืนยัน (PRD OQ-30)
