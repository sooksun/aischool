# คู่มือการใช้งาน SEIP (ฉบับย่อ)

ระบบส่งหลักฐานและประเมินผลการปฏิบัติงานตามข้อตกลง (วPA) — สำหรับครู ผู้อำนวยการ และกรรมการประเมิน

---

## 1. เริ่มต้นใช้งาน (ทุกบทบาท)

1. เปิดเบราว์เซอร์ไปที่ที่อยู่ระบบที่ผู้ดูแลแจ้ง → หน้า **เข้าสู่ระบบ SEIP**
2. กรอกอีเมลและรหัสผ่านที่ได้รับ → กด **เข้าสู่ระบบ**
3. เมนูด้านบนจะแสดงตามสิทธิ์ของท่าน:

| เมนู | ใครเห็น | ใช้ทำอะไร |
|---|---|---|
| หลักฐานของฉัน | ครู / ผอ. | ส่งและจัดการหลักฐานของตนเอง |
| จัดการรอบการประเมิน | ผอ. / ธุรการโรงเรียน | สร้างรอบประเมิน ตั้งกรรมการ |
| งานกรรมการ | ผู้ที่ถูกตั้งเป็นกรรมการ | ให้คะแนนผู้รับการประเมิน |
| รายงาน PA | ทุกบทบาท (เห็นตามสิทธิ์) | ดู/สร้างรายงานผลการประเมิน |

- ระบบต่ออายุการใช้งานให้อัตโนมัติระหว่างใช้งาน หากทิ้งไว้นานจนหลุด ให้เข้าสู่ระบบใหม่
- เลิกใช้งานให้กด **ออกจากระบบ** ทุกครั้ง โดยเฉพาะเครื่องส่วนกลาง
- ใส่รหัสผ่านผิดหลายครั้งติดกัน ระบบจะพักการเข้าสู่ระบบชั่วคราว (ประมาณ 15 นาที) — ไม่ใช่ความผิดพลาด

---

## 2. สำหรับครู — ส่งหลักฐาน

### 2.1 ส่งหลักฐานใหม่

1. เมนู **หลักฐานของฉัน** → กด **ส่งหลักฐานใหม่**
2. ทำตามขั้นตอนบนหน้าจอ (4 ขั้น):
   - **เลือกไฟล์** — PDF, รูปภาพ หรือวิดีโอ (ชนิดและขนาดที่รับขึ้นกับหมวดหลักฐาน เช่น คลิปแรงบันดาลใจจำกัด 10 นาที)
   - **กรอกรายละเอียด** — เลือกหมวดหลักฐาน ตั้งชื่อ ใส่คำอธิบาย → กด **ถัดไป**
   - **ผูกตัวชี้วัด** (ข้ามได้ มาผูกทีหลังได้) → กด **ถัดไป**
   - **ตรวจสอบก่อนส่ง** → กด **ยืนยันส่ง** → ขึ้น "ส่งหลักฐานสำเร็จ"
3. ไฟล์ที่ส่งจะมีสถานะ **รอสแกน** ก่อน — เมื่อผ่านการตรวจไวรัสจะเปลี่ยนเป็น **ปลอดภัย** จึงจะเปิดดู/ดาวน์โหลดได้ (ไฟล์ที่ไม่ผ่านจะขึ้น **ถูกบล็อก** และใช้อ้างอิงไม่ได้)

> อัปโหลดครั้งเดียว ใช้ได้หลายที่ — หลักฐานชิ้นเดียวผูกได้หลายตัวชี้วัดและถูกอ้างในหลายรายงาน ไม่ต้องส่งซ้ำ

### 2.2 ผูกหลักฐานเข้ากับตัวชี้วัด

1. เปิดหลักฐานจากรายการ → ส่วน **ตัวชี้วัดที่ผูก** → กด **ผูกตัวชี้วัดเพิ่ม**
2. เลือกตัวชี้วัดเอง หรือใช้ปุ่ม**แนะนำอัตโนมัติ**ให้ระบบเสนอตัวชี้วัดที่เข้าเค้า (ระบบวิเคราะห์ภายในเครื่องของโรงเรียน ข้อมูลไม่ออกไปภายนอก)
3. การผูกของท่านมีสถานะ "รอยืนยัน" — **ผู้อำนวยการเป็นผู้ยืนยัน** จึงจะนับใช้ในการประเมิน (ครูยืนยันของตนเองไม่ได้ และเพิกถอนการผูกที่ยังไม่ถูกยืนยันได้เอง)

### 2.3 ดูผลของตนเอง

เมนู **รายงาน PA** — เห็นเฉพาะรายงานของตนเอง คะแนนรายรอบจะเปิดให้เห็นเมื่อรอบประเมิน**ปิดแล้ว**เท่านั้น

---

## 3. สำหรับผู้อำนวยการ — จัดรอบประเมินและออกรายงาน

### 3.1 สร้างรอบการประเมิน

1. เมนู **จัดการรอบการประเมิน** → **สร้างรอบใหม่** — กำหนดปีงบประมาณ กรอบประเมิน (ครู ว9 / ผู้บริหาร ว10) และช่วงเวลา
   - รอบแบบ PA มีได้ **ปีละ 1 รอบต่อกรอบ** (ระบบกันสร้างซ้ำให้)
2. ในรอบนั้นสร้าง **รอบย่อย (Rounds)** ได้ตามจำนวนที่ต้องการ (เช่น รอบเลื่อนเงินเดือนครั้งที่ 1/2) แล้วกด **เปิดรอบ** เมื่อเริ่มประเมินจริง
3. ลำดับสถานะรอบย่อย: วางแผน → เปิดรอบ → ให้คะแนน → **ปิดรอบ** (ปิดแล้วแก้คะแนนไม่ได้ และครูจึงจะเห็นผล)

### 3.2 ตั้งคณะกรรมการ

ในรอบย่อย เลือกผู้รับการประเมิน → ตั้ง **คณะกรรมการ (3 คน)**: ประธาน 1 + กรรมการ 2

ระบบบังคับให้เอง: ต้องครบ 3 คนไม่ซ้ำกัน มีประธานคนเดียว ทุกคนต้องมีสิทธิ์ในโรงเรียนนี้ และ**ผู้รับการประเมินเป็นกรรมการของตนเองไม่ได้**

### 3.3 ยืนยันการผูกหลักฐาน

เปิดหลักฐานของครู → ตรวจแล้วกด **ยืนยันการผูกตัวชี้วัด** — เฉพาะการผูกที่ "ยืนยันแล้ว" เท่านั้นที่ถูกนำไปอ้างในรายงาน

### 3.4 สร้างรายงาน PA และดาวน์โหลด PDF

1. เมนู **รายงาน PA** → **+ สร้างรายงาน** → เลือกรอบประเมินและผู้รับการประเมิน → **สร้างและจัดทำรายงาน**
2. รายงานจะขึ้นสถานะ "กำลังจัดทำ" ครู่หนึ่ง (ระบบรวบรวมคะแนนและหลักฐานอ้างอิงให้) — หน้าจะอัปเดตเอง
3. เมื่อพร้อม กด **ดาวน์โหลด PDF ร่าง/ตรวจสอบ**

> ⚠️ PDF นี้เป็น**เอกสารร่างจากระบบสำหรับตรวจความครบถ้วน/พิมพ์อ่าน** ยังไม่ใช่แบบฟอร์มกระดาษ ก.ค.ศ. อย่างเป็นทางการ

---

## 4. สำหรับกรรมการ — ให้คะแนน

1. เมนู **งานกรรมการ** → เลือกรอบประเมิน → รอบย่อย → รายชื่อผู้ที่ท่านต้องประเมิน
   (ท่านเห็นหลักฐานได้**เฉพาะของผู้ที่ท่านเป็นกรรมการ**เท่านั้น)
2. เปิดงานประเมิน → หน้า **ให้คะแนนการประเมิน**:
   - เลือก **ผ่านเกณฑ์ภาระงาน** หรือ ไม่ผ่าน (ถ้าไม่ผ่าน = ไม่ผ่านการประเมินทันทีไม่ว่าคะแนนเท่าใด)
   - ให้คะแนนทุกตัวชี้วัด **ระดับ 1–4** โดยเทียบกับคำอธิบายระดับที่คาดหวังตามวิทยฐานะของผู้รับการประเมิน (แสดงบนหน้าจอ)
   - เปิดดูหลักฐานที่ผูกไว้ประกอบการพิจารณาได้จากหน้าเดียวกัน
3. กด **บันทึกคะแนนของฉัน** → ขึ้น "บันทึกแล้ว" (แก้ไขได้จนกว่ารอบจะปิด)
4. เมื่อครบทั้ง 3 คน ระบบคำนวณ **ผลการประเมินรวม** ให้เอง — เกณฑ์ผ่านคือ**กรรมการแต่ละคนให้ ≥ 70%** (ไม่ใช่ค่าเฉลี่ยรวม)

---

## 5. สถานะที่พบบ่อย

| สถานะ | ความหมาย |
|---|---|
| รอสแกน / ปลอดภัย / ถูกบล็อก | ไฟล์กำลังตรวจไวรัส / ใช้งานได้ / ใช้ไม่ได้ ให้ส่งไฟล์ใหม่ |
| รอยืนยัน / ยืนยันแล้ว / เพิกถอน | สถานะการผูกตัวชี้วัด — นับเฉพาะที่ยืนยันแล้ว |
| กำลังจัดทำ / รออนุมัติ / อนุมัติแล้ว | สถานะรายงาน PA |
| วางแผน / เปิดรอบ / ให้คะแนน / ปิดแล้ว | สถานะรอบย่อย — ครูเห็นผลเมื่อปิดแล้ว |

## 6. ปัญหาพบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เข้าสู่ระบบไม่ได้ | ตรวจอีเมล/รหัสผ่าน (อีเมลใช้ตัวพิมพ์เล็ก) — ถ้าผิดหลายครั้งให้รอ ~15 นาที ลืมรหัสผ่านติดต่อผู้ดูแล |
| อัปโหลดแล้วขึ้นว่าไฟล์ไม่ผ่านเงื่อนไข | ชนิด/ขนาดไฟล์ไม่ตรงกับหมวดหลักฐานที่เลือก — เปลี่ยนหมวดหรือแปลงไฟล์ (เช่น วิดีโอต้องเป็น MP4) |
| ดาวน์โหลดไฟล์หลักฐานไม่ได้ | ไฟล์ยังสถานะ "รอสแกน" — รอสักครู่แล้วรีเฟรช |
| กดบันทึกคะแนนไม่ได้ | รอบย่อยยังไม่อยู่ในช่วง "ให้คะแนน" หรือถูกปิดไปแล้ว — แจ้ง ผอ. |
| สร้างรายงานแล้วค้าง "กำลังจัดทำ" นาน | แจ้งผู้ดูแลระบบ (ตัวประมวลผลเบื้องหลังอาจไม่ทำงาน) |
| หน้าเว็บขึ้น "เกิดข้อผิดพลาดที่ไม่คาดคิด" | รีเฟรชหน้า / เข้าสู่ระบบใหม่ ถ้ายังพบให้แจ้งผู้ดูแลพร้อมเวลาที่เกิด |
